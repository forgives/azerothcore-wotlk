# World.cpp 执行流程分析文档

## 概述

`World.cpp` 是 AzerothCore 服务器核心中最重要的文件之一，负责管理整个游戏世界的生命周期。它包含了服务器的初始化、更新循环、关闭逻辑以及各种游戏系统的协调工作。

---

## 整体架构

```
┌─────────────────────────────────────────────────────────────────┐
│                        World 类架构                              │
├─────────────────────────────────────────────────────────────────┤
│  ┌──────────────┐    ┌──────────────┐    ┌──────────────┐      │
│  │   初始化阶段   │ -> │   运行阶段    │ -> │   关闭阶段   │      │
│  │SetInitialWorld│    │   Update()   │    │ ShutdownServ │      │
│  │  Settings()   │    │   (循环)     │    │    ()        │      │
│  └──────────────┘    └──────────────┘    └──────────────┘      │
└─────────────────────────────────────────────────────────────────┘
```

## 二、运行阶段 (Update)

### 2.1 主循环入口

```cpp
void World::Update(uint32 diff)
```

这是服务器运行时的核心方法，每帧调用一次，负责更新所有游戏系统。

## 八、总结

### 8.1 World.cpp 的核心职责

1. **服务器生命周期管理**
   - 初始化所有游戏系统
   - 运行主更新循环
   - 处理服务器关闭

2. **系统协调**
   - 协调各个管理器的工作
   - 确保正确的初始化顺序
   - 管理定时任务

3. **配置管理**
   - 加载和重载配置
   - 管理世界配置值

4. **时间管理**
   - 游戏时间更新
   - 任务重置时间
   - 服务器运行时间

5. **关闭管理**
   - 关闭倒计时
   - 关闭消息广播
   - 关闭取消处理

### 8.2 初始化顺序的重要性

初始化顺序非常关键，因为许多系统依赖于其他系统先加载：

```
DBC 数据 → 法术信息 → 物品模板 → 生物模板 → 任务 → 区域触发器 → 副本
```

错误的顺序会导致数据引用失败或服务器崩溃。

### 8.3 Update 循环的性能考虑

Update 方法每帧调用，性能至关重要：

- 使用定时器避免每帧执行某些操作
- 使用缓存减少数据库查询
- 异步处理数据库回调
- 使用 METRIC_TIMER 监控性能
